# HavenStay historical evidence

HavenStay is a side-by-side hotel marketplace build created before Lamina’s transactional product graph runtime.

It remains useful evidence for the product-design question: does an explicit behavior workflow surface marketplace states, permissions, operations, and failure handling that a general coding prompt misses?

It is **not** a current installation, storage, command, or benchmark tutorial. Its historical artifacts do not demonstrate `graphd`, Ladybug, CocoIndex observations, `GraphVersion` receipts, or Persona Mission isolation.

For current adoption, use [the first workflow](/getting-started/quickstart). For maintained benchmark status, use [LaminaBench LB6](/advanced/lamina-bench).
