# LaminaBench LB6 status

LaminaBench 6 (LB6) is the current benchmark line. Earlier “v4” documentation and duplicated command recipes are obsolete.

LB6 evaluates product-behavior work under matched agent budgets and multiple arms. Publication is fail-closed: a benchmark claim requires validated task packages, sealed execution artifacts, compatible replay, semantic-row validation, and a maintained release artifact.

This page intentionally does not duplicate volatile runner commands, model claims, or unpublished results.

Use the maintained sources:

- [LB6 benchmark source](https://github.com/aryaniyaps/lamina/tree/main/benchmarks/lb6)
- [LB6 methodology and runbooks](https://github.com/aryaniyaps/lamina/tree/main/benchmarks/lb6/README.md)
- [Current public release artifact](https://github.com/aryaniyaps/lamina/tree/main/benchmarks/releases/current)

If the current release artifact is absent, invalid, or not in a publishable status, no performance claim should be inferred from repository code or local reports.

HavenStay is historical comparison evidence, not an LB6 result.
