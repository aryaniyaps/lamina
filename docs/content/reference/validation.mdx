# Validation

```bash
lamina graph validate --at HEAD
lamina graph validate --at <session-id>
```

The installed engine checks Statement shape/references, aliases, workflow ordering/reachability, lifecycle transitions, actor authority, dependencies, proof/evidence coverage, Mission capability compatibility, epistemic ingress, Contradictions, uniqueness, and cycles. If an affected closure cannot be proven complete, validation uses the whole branch view.

Approval additionally requires current reproducible evidence and no relevant Contradiction. Agents cannot add executable validators or approve their own output.
