# Legacy run-file schema

This page is retained only to explain pre-transactional Lamina artifacts.

Legacy run files are not canonical, are not discovered or selected by production commands, and are never dual-written. Existing files remain untouched and may be indexed by CocoIndex as source evidence like any other business document.

Use [Transactional graph](/reference/transactional-graph) for the current Resource, Statement, GraphVersion, session, observation, Mission, Run, and evidence model.
