# Storage and projections

Canonical runtime state lives in the Git common directory’s `lamina/` folder: Ladybug database, CocoIndex tracking, evidence CAS, lock, and socket.

Business context, Persona JSON, source documentation, and old Lamina files are indexable source evidence. They are not graph state.

Markdown deliverables are generated from a resolved GraphVersion query and must name the GraphVersion and source revision. They are never read back into the runtime.
