# Glossary

**Resource** — stable opaque product-knowledge identity with a generic kind.

**Statement** — normalized subject/predicate/object-or-literal fact with optional scope and qualifiers.

**GraphVersion** — immutable version delta and validation receipt.

**GraphView** — branch, session, observation, or historical view.

**Contradiction** — Resource referencing incompatible Statements or alias identities.

**Mission** — Persona-specific executable verification plan.

**Run** — isolated Mission execution tied to a starting GraphVersion and source revision.

**HarnessResult** — normalized adapter event sequence.

**Observation** — CocoIndex-derived source evidence with explicit reproducible provenance.
