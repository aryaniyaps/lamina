# Glossary

**Actor** — A product role with authority for operations.

**Alias** — Human-readable key resolving to a stable opaque Resource id.

**Contradiction** — Stable Resource representing incompatible active facts. Conflicting facts remain visible.

**Evidence input** — A source file or artifact that may support a proposal but is not canonical by location alone.

**Epistemic class** — Origin category: `intended`, `observed`, `inferred`, `simulated`, `human_evidence`, or `runtime_evidence`.

**GraphView** — A branch, session, observation, or historical view of graph membership.

**`graphd`** — Authenticated clone-local daemon and sole Ladybug writer.

**`GraphVersion`** — Immutable graph delta, parent set, source revision, and validation receipt.

**HarnessResult** — Normalized result produced by a Mission adapter.

**Ladybug** — Embedded graph database containing canonical clone-local product state.

**Mission** — Persona-specific executable verification contract.

**Observation** — CocoIndex-produced source evidence with snapshot and extractor provenance.

**Persona** — A concrete user perspective that can assume an Actor.

**Projection** — Human-readable implementation or verification handoff resolved from a graph view.

**Resource** — Stable graph node such as Product, Actor, Persona, Workflow, Operation, Proof, Mission, or Run.

**Run** — One isolated execution of a Mission.

**Session** — Transactional staging view with a base version and compare-and-swap publication.

**Statement** — Normalized relationship or typed fact with subject, predicate, object/literal, qualifiers, scope, and evidence.
