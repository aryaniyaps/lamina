# Evidence inputs

## `.lamina/business-context.md`

Human-editable domain evidence: problem, users, scope, constraints, terminology, and change history. CocoIndex can observe it. A trusted Lamina workflow proposes the resulting Product and intent knowledge through `graphd`.

## `.lamina/personas.json`

Human-editable actor and persona evidence. It is validated before use, observed like other source, and converted into explicit graph proposals.

## Source files

CocoIndex produces Observation envelopes with source snapshot, content hash, locator, extractor identity/version, and normalized payload. Observations are `observed`, never intended or runtime evidence.

## Projections

Implementation plans, reports, and fix lists may be generated from a resolved `GraphVersion`. They are handoffs, not inputs with canonical authority.

## Runtime artifacts

Screenshots, traces, logs, and other files become useful evidence only when a normalized Mission event references their path and digest. Missing or changed artifacts make the evidence stale.

## Authority rule

No file becomes canonical merely because it lives under `.lamina/`. Canonical membership changes only through a validated `graphd` transaction.
