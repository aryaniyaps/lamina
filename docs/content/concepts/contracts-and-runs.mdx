# GraphVersions and Runs

A GraphVersion is the immutable, validated state of a branch view. A session stages typed mutations against a base GraphVersion and publishes with compare-and-swap in one Ladybug transaction.

A Run is runtime product knowledge tied to its starting GraphVersion, source revision, Persona Mission, adapter context, and HarnessResult. Runs are isolated until publication.

Human implementation, report, and fix documents are optional query projections. They never become canonical inputs.
