# The loop

1. `/lamina-init` records/indexes business evidence and publishes inferred Product/Persona/Actor proposals grounded in explicit user input.
2. `/lamina-design` publishes a validated GraphVersion.
3. A normal coding session implements the GraphVersion projection.
4. `/lamina-verify` runs every relevant Persona Mission in an isolated session, inspects the normalized evidence, then explicitly publishes accepted Run sessions.
5. Query the semantic diff and repeat.

Lamina commands do not edit product source.
