# Lamina

Lamina gives AI coding agents a centralized, transactional product graph.

```text
Sources ──▶ CocoIndex ──observations──▶ graphd ──▶ Ladybug
Agents  ──typed proposals─────────────▶ graphd ──▶ Ladybug
Runs    ──normalized evidence─────────▶ graphd ──▶ Ladybug + evidence CAS
```

Ladybug is the canonical local knowledge graph. It stores stable Resources, normalized Statements, versions, branch/session/observation views, Missions, Runs, and evidence. Git identifies source revisions and branches but does not store graph changes.

## Start

```bash
npm install -g @laminadev/cli
npx skills add aryaniyaps/lamina --skill lamina -a '*' -y
lamina doctor --json
/lamina-init
/lamina-design
# implement in a normal coding session
/lamina-verify
```

Use `lamina graph status` to inspect the resolved GraphVersion. Design and verification commands do not edit application source.

## Why it is different

- Serializable sessions commit completely or leave the branch unchanged.
- Intent, observations, agent inference, Persona simulation, human evidence, and runtime evidence stay separate.
- Conflicts remain inspectable as Contradictions.
- Every relevant Persona receives an independent Mission and Run.
- Source changes update an observation view without mutating canonical Claims.
- Existing legacy run files are ignored by the runtime.
