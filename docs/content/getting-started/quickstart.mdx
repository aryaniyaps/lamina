# Quickstart

```bash
npm install -g @laminadev/cli
npx skills install aryaniyaps/lamina
lamina doctor --json
/lamina-init
/lamina-design
lamina graph status
# implement the resolved GraphVersion in a normal coding session
/lamina-verify
```

Run `lamina graph observe` after source changes. Use `lamina graph diff --base main --head HEAD` for a semantic branch diff.
