# Installation

Lamina works with any AI coding agent and any stack. Install once in your **shell**, then invoke Lamina with **slash commands in agent chat** — not with passive natural-language prompting.

<Callout type="warning">
Installation does not cause Lamina to activate. After install, open your project root and start a **fresh agent session**, then run `/lamina-init` directly.
</Callout>

## Quick path

1. **Shell** — install the CLI, then install the skills for your agent
2. Open your project root and start a **fresh agent session** so the skill loads
3. **Agent chat** — run `/lamina-init <your product domain and primary users>`

Continue with [Quickstart](/getting-started/quickstart) for the full design → implement → verify loop.

## Quick install

```bash
npm install -g @laminadev/cli
npx skills add aryaniyaps/lamina --skill lamina -a '*' -y
```

The CLI and skill bundle have independent release and installation lifecycles.
The CLI provides `lamina`; the GitHub install provides one public `lamina`
skill containing all 58 workflow and craft modules. That bundle routes
`/lamina`, `/lamina-init`, `/lamina-design`, and `/lamina-verify` internally,
so supporting modules do not pollute the agent's top-level skill catalog.
Either component can be installed alone, but graph-backed workflows require
CLI API 1.

## Agent-specific installs

### Cursor

```bash
npx skills add https://github.com/aryaniyaps/lamina --skill lamina -a cursor -y
```

### Claude Code

```bash
npx skills add https://github.com/aryaniyaps/lamina --skill lamina -a claude-code -y
```

### Codex / Pi / generic

```bash
npx skills add https://github.com/aryaniyaps/lamina --skill lamina -a codex -a pi -y
```

## Prerequisites

- An AI coding agent (Cursor, Claude Code, Codex, Gemini, Pi, or similar)
- Any framework, database, and UI library — Lamina is stack-agnostic
- Node.js 20 or newer for `@laminadev/cli`

There is no Node.js requirement to install the skills alone. If the compatible
CLI is absent, a graph-backed workflow stops before mutation and prints:

```text
npm install -g @laminadev/cli@latest
```

The skills never invoke `npx` for the runtime and never auto-install it.

## After install

1. Open the intended **project root** in your coding agent
2. Start a **fresh agent session** — skills load at session start
3. Run init directly in agent chat:

```
/lamina-init <your product domain and primary users>
```

Successful init produces and validates both `.lamina/business-context.md` and `.lamina/personas.json`. Run init **once per project or domain**; use `/lamina-init update` only when the business use case, market, scope, or actor cast materially changes.

<Callout type="info">
Not sure which command to run? `/lamina <what you are trying to do>` is an optional router for discovery — not a required setup step and not a substitute for `/lamina-init`.
</Callout>

## Update

Update the components independently:

```bash
npm install -g @laminadev/cli@latest
npx skills add aryaniyaps/lamina --skill lamina -a '*' -y
```

Start a new agent session after updating.

## Migrate from the old linked repository package

If a previous checkout was linked globally as `lamina`, unlink it before
installing the standalone package:

```bash
npm unlink -g lamina
npm install -g @laminadev/cli
npx skills add aryaniyaps/lamina --skill lamina -a '*' -y
```

Do not delete `.git/lamina`. Existing `graph.lbdb` data is retained; the new
protocol v3 daemon creates its authentication token beside that database.

## .gitignore guidance

Lamina writes evidence inputs and optional projections to `.lamina/`. The
canonical Ladybug graph remains clone-local under `.git/lamina` and is never
shared by committing `.lamina/`.

| Approach | When |
|----------|------|
| Commit selected `.lamina/` files | Team wants shared business evidence or non-canonical projections |
| Gitignore `.lamina/` | Personal experiments; regenerate locally |

To exclude:

```gitignore
.lamina/
```

## Uninstall

Remove the Lamina skill using your agent's skill management tooling, or delete
the installed skill directory. Remove the CLI separately with
`npm uninstall -g @laminadev/cli`. `.lamina/` artifacts and `.git/lamina`
graph data are not removed automatically.
