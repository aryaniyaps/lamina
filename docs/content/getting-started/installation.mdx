# Install Lamina

Install the CLI and the agent skills independently from your project root:

```bash
npm install -g @laminadev/cli@latest
npx skills add aryaniyaps/lamina --all -y
lamina --version
lamina doctor --json
```

Node.js 20 or newer is required. Source observation additionally needs [`uv`](https://docs.astral.sh/uv/); core graph, session, and mission commands do not.

<Callout type="warning">
With npm 12, dependency install scripts are blocked until approved. Ladybug needs its native install script, so use `npm install -g --allow-scripts=@ladybugdb/core @laminadev/cli@latest`. npm 11 users can use the standard command above.
</Callout>

The skills installer adds `/lamina`, `/lamina-init`, `/lamina-design`, and `/lamina-verify` for supported coding agents. The CLI provides the JSON `lamina` command. Graph-backed skills require CLI API 1.

## Verify the installation

`lamina --version` should print `0.1.0` or newer. `lamina doctor --json` should return:

```json
{
  "ok": true,
  "cli": {
    "package": "@laminadev/cli",
    "version": "0.1.0",
    "api_version": 1
  },
  "graph": {
    "protocol_version": 3
  }
}
```

The full report also describes Node, Git, platform transport, `uv`, and Python 3.13 readiness.

Start a **fresh agent session** after installing or updating skills. Skill discovery happens when the agent session starts; installation does not activate Lamina passively.

## First invocation

Open the intended Git repository and run this in agent chat:

```text
/lamina-init <your product domain and primary users>
```

Successful initialization writes `.lamina/business-context.md` and `.lamina/personas.json`, validates them, observes the repository, and publishes Product, Actor, and Persona knowledge through `graphd`.

Those two files are evidence inputs. Editing them does not directly mutate canonical graph state; a Lamina workflow must observe and publish the resulting proposal.

## Update

```bash
npm install -g @laminadev/cli@latest
npx skills add aryaniyaps/lamina --all -y
lamina doctor --json
```

For npm 12, retain `--allow-scripts=@ladybugdb/core` on the CLI install command. Start a new agent session afterward.

## Migrate a linked development install

```bash
npm unlink -g lamina
npm install -g @laminadev/cli@latest
npx skills add aryaniyaps/lamina --all -y
```

Do not delete `.git/lamina`. The standalone package reuses the canonical graph under the Git common directory.

## Uninstall

```bash
npm uninstall -g @laminadev/cli
```

Remove the installed skills with your agent’s skill manager. Uninstalling does not delete `.lamina/` evidence files or the canonical graph. Back up and remove those only as an explicit data-retention decision.
