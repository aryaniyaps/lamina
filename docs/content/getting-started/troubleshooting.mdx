# Troubleshooting

- `LAMINA_COMPARE_AND_SWAP_FAILED`: rebase the session, query the new head, revalidate, and publish.
- graphd unavailable: rerun `lamina graph status`; stale lock/socket files are recovered only when the recorded process is dead.
- observation update incomplete: ensure graphd is live and rerun `npm run graph:observe`; CocoIndex reconciles possible prior states.
- stale readiness: inspect missing evidence, source snapshot changes, artifact digests, and Contradictions with `lamina graph validate`.
