# `/lamina-design`

Shapes intended product behavior in an explicit graph session.

1. Requires valid business context.
2. Queries the active GraphVersion and source observations.
3. Proposes typed Resources and normalized Statements.
4. Validates the affected closure.
5. Compiles a Mission for every relevant Persona.
6. Publishes the session atomically.

```bash
lamina graph status
lamina session start
lamina graph validate --at <session-id>
lamina session publish <session-id>
```

On a stale-base error, rebase, re-query, and revalidate. Application implementation is a separate coding session. Any implementation Markdown is a query projection tied to a GraphVersion.
