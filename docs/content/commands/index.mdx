# Commands

| Command | Purpose |
|---|---|
| `/lamina-init` | Establish business evidence and Product/Persona/Actor Resources |
| `/lamina-design` | Validate and publish intended product behavior |
| `/lamina-verify` | Run every relevant Persona Mission |
| `/lamina` | Route focused product work |

Runtime operations use `lamina graph`, `lamina session`, and `lamina mission`. See [Transactional graph](/reference/transactional-graph).
