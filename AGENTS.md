# Lamina repository instructions

This repository contains Lamina itself. Do not run Lamina's product-graph,
Persona-walk, ImplementationPacket, WorkMap, observation, Mission, or
`lamina work verify` workflow as a prerequisite for changing this repository.
Develop and validate Lamina directly with its repository tests and release
checks.

The self-hosting exemption applies only to this repository. The workflow
implemented and documented here remains the supported contract for downstream
projects that initialize Lamina.
